# 信号分析记录模板 v1.0

模板由 HseeHub 编辑部提供，许可为 CC BY 4.0；本模板的许可不覆盖你填入的数据、代码或图片。2026-10-03 补充记录字段，模板版本保持 v1.0。

先看 [一份可复算的合成数据示例](/project-examples/signal-evidence-example.md)，再把下面的空白项换成自己的记录。没有执行的步骤写“未执行”，不要把预期结果填成实际结果。

## 1. 问题与边界

- 记录人、日期与本次版本：
- 我想观察什么：
- 这次练习不回答什么：
- 本人完成的部分 / 参考或合作完成的部分：

## 2. 数据与参数

- 数据类型与生成方式：
- 原始输入位置、文件版本与标签来源：

- 样本量、采样间隔和标签：
- 执行环境（系统、语言/工具及版本、依赖）：
- 运行入口、命令与预期耗时：
