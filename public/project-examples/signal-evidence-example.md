## 1. 这次回答什么

问题：对给定的合成特征，用一条固定阈值规则，如何把每个判断追溯到样本，并复算二分类指标？

正类定义：人工标签 1；负类为人工标签 0。数字不对应疾病或真实生理状态。这里没有独立的现实标签来源，不能据此评价模型对真实人群的表现。

编辑完成：构造输入表、固定划分、制定规则、展开指标及误例。未完成：波形处理、模型拟合、新数据验证、真实采集。

## 2. 输入与固定条件

- 输入许可：以下手工合成表由 HseeHub 编辑部创建，按 CC BY 4.0 提供；这一许可不延伸到你以后替换进来的外部数据。
- 输入版本：本文件的 2026-10-03 版本；共 12 条记录，其中 4 条用于确定规则、8 条保留作测试。
- 特征：无量纲示意分数 `x`，不是从波形实际提取的特征。
- 生成方式：手工指定；随机种子、采样间隔不适用。
- 执行环境：下方无依赖 JavaScript 可在 Node.js 中运行；本轮算数复核使用 Node.js v24.14.1。它不运行分类训练流程。
- 固定条件：只依据下面 4 条训练记录确定阈值；测试记录不参与选阈值。不设验证集，因为这里只有一次预定规则演示，没有调参比较。

| 训练样本 ID | x | 人工标签 |
| --- | ---: | ---: |
| train-01 | 0.10 | 0 |
| train-02 | 0.30 | 0 |
| train-03 | 0.70 | 1 |
| train-04 | 0.90 | 1 |

规则确定方式：取训练负类最大值 `0.30` 和正类最小值 `0.70` 的中点，得到阈值 `(0.30 + 0.70) / 2 = 0.50`。`x >= 0.50` 预测为 1，否则为 0。这是手工规则，不称为训练完成的机器学习模型。

## 3. 测试记录与实际算数结果

| 测试样本 ID | x | 人工标签 y | 阈值规则预测 | 类型 |
| --- | ---: | ---: | ---: | --- |
| test-01 | 0.20 | 0 | 0 | TN |
| test-02 | 0.40 | 0 | 0 | TN |
| test-03 | 0.55 | 0 | 1 | FP |
| test-04 | 0.65 | 0 | 1 | FP |
| test-05 | 0.45 | 1 | 0 | FN |
| test-06 | 0.60 | 1 | 1 | TP |
| test-07 | 0.80 | 1 | 1 | TP |
| test-08 | 0.90 | 1 | 1 | TP |

TP 是预测 1 且标签 1，TN 是预测 0 且标签 0；FP 是误报，FN 是漏报。由表直接计数：`TP = 3`、`TN = 2`、`FP = 2`、`FN = 1`。

- 准确率：`(TP + TN) / 8 = 5 / 8 = 62.5%`。
- 精确率：`TP / (TP + FP) = 3 / 5 = 60%`。
- 召回率：`TP / (TP + FN) = 3 / 4 = 75%`。
- F1：`2TP / (2TP + FP + FN) = 6 / 9 ≈ 66.67%`。

这些只是 8 条预设记录上的算数，不代表经过独立采样估计的泛化能力。显示时可四舍五入，计算时使用原始分数。

### 自己复算一次

保存下面代码为 `verify-signal.mjs`，运行 `node verify-signal.mjs`。输入直接对应上表，输出是计数及 0 到 1 之间的指标。

```js
const train = [
  { id: 'train-01', x: 0.10, y: 0 },
  { id: 'train-02', x: 0.30, y: 0 },
  { id: 'train-03', x: 0.70, y: 1 },
  { id: 'train-04', x: 0.90, y: 1 },
];
const test = [
  { id: 'test-01', x: 0.20, y: 0 },
  { id: 'test-02', x: 0.40, y: 0 },
  { id: 'test-03', x: 0.55, y: 0 },
  { id: 'test-04', x: 0.65, y: 0 },
  { id: 'test-05', x: 0.45, y: 1 },
  { id: 'test-06', x: 0.60, y: 1 },
  { id: 'test-07', x: 0.80, y: 1 },
  { id: 'test-08', x: 0.90, y: 1 },
];
const threshold = (
  Math.max(...train.filter(row => row.y === 0).map(row => row.x)) +
  Math.min(...train.filter(row => row.y === 1).map(row => row.x))
) / 2;
let TP = 0, TN = 0, FP = 0, FN = 0;
for (const { x, y } of test) {
  const prediction = Number(x >= threshold);
  if (prediction === 1 && y === 1) TP++;
  else if (prediction === 0 && y === 0) TN++;
  else if (prediction === 1) FP++;
  else FN++;
}
console.log({
  threshold, TP, TN, FP, FN,
  accuracy: (TP + TN) / test.length,
  precision: TP / (TP + FP),
  recall: TP / (TP + FN),
  f1: 2 * TP / (2 * TP + FP + FN),
});
```

## 4. 从误例得到下一步

`test-03`、`test-04` 的分数高于阈值，却被编辑标为 0；`test-05` 的分数低于阈值，却被标为 1。这说明在这张预设表里，单一阈值不能把两类完全分开。

不能据此断言“噪声导致了误判”，因为本例没有噪声生成过程。下一步可以另建一组独立合成样本并预先写出生成规则，再检查误例是否仍集中在阈值附近。不要看过本测试结果后改阈值，再把同一张表称为未见过的测试集。
